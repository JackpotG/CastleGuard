# 03 第一阶段：Axmol（Cocos2d-x C++ 裸引擎）开发清单

> 对应路线图第一站。按周排布，每项标注对应的学习目标。**顺序即优先级，不要跳。**
> 技术路线（2026-11-13 变更）：弃用 Cocos Creator 图形化开发，改用 Axmol 纯 C++ 代码开发；上架链路为 Emscripten → WASM → 微信通用引擎适配方案，降级预案为 H5 + Android APK 发布。

## 第 1~2 周：战斗原型（M0）

目标：一张图、一种怪、只有射箭，但手感必须对。

- [x] 环境搭建：安装 CMake + 编译器（VS2022/Xcode），拉取 Axmol 引擎并 setup（锁定 Emscripten 3.1.51），`axmol new` 新建 C++ 项目，桌面端跑通 Hello World；再验证 `axmol run -p wasm` 浏览器可运行；**最后用官方转换工具把 WASM 包转换为微信小游戏并在微信开发者工具中跑通**——用最小成本把整条上架链路提前排雷（2026-11-16 完成；实际锁定 emsdk 3.1.73、不装完整 Xcode 改用 CLT+Ninja，详见 docs/04）
- [x] 场景骨架：城堡（左）、出怪线（右）、地面 —— *学习：场景树、节点层级、分辨率适配策略*（2026-11-16 完成；落地为**双视角版本**：2 版伪 2.5D 斜俯视=原作构图主线[底墙/顶出怪线/纵车道+纵深色带]，1 版纯侧视=新增风格[底地面条/左灰房子/右出怪口]，按 1/2 键或双指或调试按钮切换；全部按比例布局 + 尺寸变化自动重排，横竖屏共用一套布局代码，详见 docs/01 视角决策）
- [x] 射箭系统：点击屏幕 → 从城堡向点击方向射出箭矢，命中判定 —— *学习：输入事件、向量数学、对象池（第一天就上，别后补）*（2026-11-16 完成：点击射箭，方向向量 normalize × 恒定速率，32 支箭对象池零 new/delete，出界回收；`ARROW_GRAVITY` 一个常量切换直线/抛物线；箭尖命中判定集中在 `updateArrows()`，等怪物系统接入目标）
- [ ] 怪物系统：一种怪从右走到左，撞墙扣血 —— *学习：Prefab、组件挂载、简单状态机（走/攻击/死）*
- [ ] 波次管理：数据驱动的波次配置（JSON 配置怪物类型/数量/间隔）—— *学习：数据与逻辑分离*
- [ ] **验收：真机上连续玩 10 分钟不烦，射箭指哪打哪不别扭**

手感调优清单（逐项过）：箭矢飞行速度、箭的抛物线 vs 直线、命中反馈（音效/顿帧/粒子）、连点射速上限。

## 第 3~4 周：MVP 闭环（M1）

- [ ] 技能系统 ×3：AOE 火球、冰冻减速、箭雨 —— *学习：技能冷却/耗蓝、AOE 判定、特效层级管理*
- [ ] 怪物扩展到 5 种：普通、快速、护盾（免箭怕技能）、自爆、Boss —— *学习：继承/组合复用怪物逻辑*
- [ ] 结算与经济：击杀得金币、过关得水晶 —— *学习：单例数据管理、存档（localStorage/微信存档 API）*
- [ ] 局外升级界面：弓箭三线 + 城墙 + 技能解锁 —— *学习：UI 系统、ScrollView、数值表驱动*
- [ ] 5 关数值验证，第 3 关放首个技能解锁作为爽点
- [ ] **验收：一个没看过说明的朋友能自己玩通 5 关**

## 第 5~6 周：优化系统（M2）

- [ ] Roguelike 三选一：Boss 波后弹出增益三选一（多重箭/射速/暴击/元素附伤…）—— *学习：Buff 系统设计（修饰器模式）*
- [ ] 好友排行榜：微信开放数据域接入 —— *学习：开放数据域子包、平台 API*
- [ ] 分享挑战：生成战绩分享卡片
- [ ] 激励视频：复活一次 / 双倍结算 / 每日免费水晶 —— *学习：广告 SDK、广告位设计不伤体验*
- [ ] 性能专项：同屏 100+ 实体压测，把帧率曲线拉出来看 —— *渲染课：draw call 统计、合批、图集整理、粒子数量预算*
- [ ] **验收：中低端安卓机（找台旧手机）全程 50fps+**

## 第 7 周：上线冲刺（M3）

- [ ] 备案与资质：小游戏备案、实名认证、防沉迷接入
- [ ] 基础数据埋点：关卡流失点、广告点击率
- [ ] 提审、上线、种子用户投放（朋友圈/群）
- [ ] 复盘文档：次留率、第 3 关流失率、广告 eCPM，写进 `docs/复盘-第一站.md`

## 素材策略（全项目通用）

- 临时占位：itch.io / OpenGameArt 免费素材，原型阶段绝不自己画
- 正式版本：购买授权素材包或定制（预算留 500~2000 元）
- **禁用原作任何素材**（详见 01-项目上下文 合规红线）
- 归档约定：`assets-source/` 存引擎无关源文件（PNG/Spine/数值 JSON），导入引擎时走各引擎自己的 assets 目录
