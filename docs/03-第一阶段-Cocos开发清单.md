# 03 第一阶段：Axmol（Cocos2d-x C++ 裸引擎）开发清单

> 对应路线图第一站。按周排布，每项标注对应的学习目标。**顺序即优先级，不要跳。**
> 技术路线（2026-11-13 变更）：弃用 Cocos Creator 图形化开发，改用 Axmol 纯 C++ 代码开发；上架链路为 Emscripten → WASM → 微信通用引擎适配方案，降级预案为 H5 + Android APK 发布。

## 第 1~2 周：战斗原型（M0）

目标：一张图、一种怪、只有射箭，但手感必须对。

- [x] 环境搭建：安装 CMake + 编译器（VS2022/Xcode），拉取 Axmol 引擎并 setup（锁定 Emscripten 3.1.51），`axmol new` 新建 C++ 项目，桌面端跑通 Hello World；再验证 `axmol run -p wasm` 浏览器可运行；**最后用官方转换工具把 WASM 包转换为微信小游戏并在微信开发者工具中跑通**——用最小成本把整条上架链路提前排雷（2026-11-16 完成；实际锁定 emsdk 3.1.73、不装完整 Xcode 改用 CLT+Ninja，详见 docs/04）
- [x] 场景骨架：城堡（左）、出怪线（右）、地面 —— *学习：场景树、节点层级、分辨率适配策略*（2026-11-16 完成；落地为**双视角版本**：2 版伪 2.5D 斜俯视=原作构图主线[底墙/顶出怪线/纵车道+纵深色带]，1 版纯侧视=新增风格[底地面条/左灰房子/右出怪口]，按 1/2 键或双指或调试按钮切换；全部按比例布局 + 尺寸变化自动重排，横竖屏共用一套布局代码，详见 docs/01 视角决策）
  - 2026-11-18 战场识别优化：移除两种视角中用于标记发射点的红旗，改为带弓臂、弓弦和握把的完整主弓；同一套矢量武器按当前射击目标实时旋转，点射、长按与拖动改向都会先更新弓身朝向。装填完成时直接把真实对象池箭挂到弓上，多重箭按实际数量和扇形角度同时挂载；发射时同一批箭保留世界位置重新挂回场景并进入飞行，弓身播放压缩回弹，冷却期间保持空弓，不再维护重复的搭载箭表现。多重箭使用整组预留、整组显示、整组发射的原子规则，池槽不足时等待完整齐射，不会逐支装填；开发者工具允许把箭速调到 0，使箭停在发射位置检查挂载与脱离效果。
- [x] 射箭系统：点击屏幕 → 从城堡向点击方向射出箭矢，命中判定 —— *学习：输入事件、向量数学、对象池（第一天就上，别后补）*（2026-11-16 完成：点击射箭，方向向量 normalize × 恒定速率，32 支箭对象池零 new/delete，出界回收；`ARROW_GRAVITY` 一个常量切换直线/抛物线；箭尖命中判定集中在 `updateArrows()`，等怪物系统接入目标）
  - 2026-11-18 操作增强：按下立即射击，保持按住时沿用射速冷却自动续射；拖动可连续改变瞄准方向，抬起或触摸取消立即停止。技能拖放、调试按钮和模态界面仍优先，不会触发穿透射击。
- [x] 怪物系统：一种怪从右走到左，撞墙扣血 —— *学习：Prefab、组件挂载、简单状态机（走/攻击/死）*（2026-11-16 完成：DrawNode 占位小恶魔 48 只对象池，Walk/Attack/Dead 状态机，箭尖圆碰撞命中即死；怪群感三件套 = 12 车道加密 + 0.8s 出怪 + 同车道横向抖动与个体速度 85%~115% 随机；桌面 + 微信双端验证通过）
- [x] 波次管理：数据驱动的波次配置（JSON 配置怪物类型/数量/间隔）—— *学习：数据与逻辑分离*（2026-11-17 完成：`Content/config/waves.json` 三层结构——JSON 配置 → 只读镜像 WaveConfig → 运行时 SpawnGroupRuntime；波次状态机 Idle/Spawning/Resting/AllClear；组字段 type/count/interval/delay/lane/from（left/right 侧翼突袭）；新怪类型 normal/fast/ranged 全靠类型表驱动，远程怪停火线+弹丸池；调试面板 ⇄ 切视角 / ↻ 重开 / ◀▶ 跳波（桌面 1/2、R、Q/E）；配置加载失败有内置兜底波；桌面 + 微信双端验证通过）
- [x] **验收：真机上连续玩 10 分钟不烦，射箭指哪打哪不别扭**（2026-11-17 通过：iPhone 真机扫码预览验证，matchMedia 垫片时序修复后运行正常，见 docs/04 排雷 21）

手感调优清单（逐项过）：箭矢飞行速度、箭的抛物线 vs 直线、命中反馈（音效/顿帧/粒子）、连点射速上限。

- [x] 怪物扩展到 5 种：普通、快速、护盾（免箭怕技能）、自爆、Boss —— *学习：继承/组合复用怪物逻辑*（2026-11-17 完成：实际扩展到 **13 种**——普通/快速/远程/护盾/自爆/飞行/护符/治疗/分裂/狂暴/幽灵/召唤/Boss；设计准则="每种怪逼玩家换一种应对方式 + 读图识怪（专属零件）+ 组合克制"；技术主线=spawnMonster 重构为 allocMonster/setupMonster/spawnMinion 两段式，战中生怪（分裂子体/召唤物）与波次出怪共用初始化；怪物状态机复用：飞行怪/Boss 游荡=Attack 状态内行为，前摇=windupTimer 互斥停滞；波次扩到 12 波；桌面+微信双端验证）

- [x] 结算与经济：击杀得金币、过关得水晶 —— *学习：单例数据管理、存档（localStorage/微信存档 API）*（2026-11-17 完成：纯逻辑 `EconomyModel` 统一奖励规则=每次击杀 1 金币、守住全部波次 5 水晶，`GameData` 单例统一管理钱包与存档；桌面走 Axmol `UserDefault`，浏览器 WASM 走 `localStorage`，微信小游戏走 `wx.getStorageSync/setStorageSync`；战斗 HUD 实时显示本局金币，胜败结算层统一入账并提供正式版“再来一局”；波次起点检查点防止旋转/切视角重播当前波时重复刷金币；5 个 doctest 用例 37 个断言全部通过，桌面与 WASM 编译通过）
- [x] 局外升级界面：弓箭三线 + 城墙 + 技能解锁 —— *学习：UI 系统、ScrollView、数值表驱动*（2026-11-17 完成：结算页进入“城堡工坊”，Axmol `ScrollView` 承载强弓/疾射/多重箭/城墙四条成长线和四技能状态；`Content/config/upgrades.json` 统一配置价格、等级效果与解锁条件，购买规则由纯逻辑 `ProgressionModel` 扣款并交给 `GameData` 跨平台持久化，旧版钱包存档可迁移；升级真实接入箭伤、射速、扇形多重箭和下一局城墙上限，闪电默认锁定并以 5 水晶解锁；8 个 doctest 用例 52 个断言、桌面与 WASM 编译通过，竖屏界面截图检查通过）
