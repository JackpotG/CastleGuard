# 游戏策划配置 App

macOS 独立窗口应用，统一进入关卡配置、技能树配置和基础数值。首页还可直接进入军械所、研究院、城防营、法术研习。三个工具共用一份编辑状态，返回工作台或切换工具不会清空草稿；只有点击当前工具的“保存配置”才写入游戏配表。

## 打开

双击仓库根目录的 **游戏策划配置.app**，也可将它拖入 Dock。首次拉取源码后没有应用时，双击根目录的 **游戏策划配置.command**，自动构建并打开；已有应用需要更新时，先保存并退出，再运行该脚本。

也可以在仓库根目录执行：

```bash
python3 tools/planner-app/build.py
```

生成的 `.app`、图标和编译缓存属于本机产物，不加入 Git。构建只需本机已有的 Command Line Tools，不依赖完整 Xcode、Electron 或额外的桌面框架。应用目前支持 macOS 13 及以后版本，只构建当前机器的架构。

## 使用与生命周期

- `⌘S` 保存当前工具，`⌘0` 返回工作台；输入框仍在编辑时，会先提交当前输入再保存。
- 顶部“重新载入”同时刷新配置、页面脚本和连线模块；请先保存需要保留的草稿。更新前已打开的旧窗口需先保存、退出再打开一次。
- 关闭窗口或 `⌘Q` 时先检查所有工具的未保存状态，可以继续编辑或放弃后退出。
- 应用自动启动自己的配置服务，由系统分配空闲端口，避免与浏览器工具或游戏服务冲突；退出只结束自己创建的服务。
- 服务异常停止时可选择重新连接，复用原端口与原页面以保留草稿。
- 服务日志、就绪文件保存在系统临时目录，正常退出后清理；程序日志统一使用 `[PlannerApp]` 前缀。
- 应用记录构建时的项目路径与 Python 路径。移动仓库或更换 Python 后，重新构建应用；拖动 `.app` 的位置不影响它找到原项目。

浏览器仍可使用原启动命令，并通过 `http://127.0.0.1:8780/planner` 打开工作台，或通过 `/` 打开原关卡页面。技能树连线路由仍由游戏的 C++ 源码编译共用，参见 `../config-editor/README.md`。
