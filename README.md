# CastleGuard

> 以复刻并优化经典塔防手游《Defender II》（守卫者2）为主线，系统学习游戏开发：引擎、渲染、开发流程与独立游戏制作。

## 项目定位

这不是一个"做完就扔"的复刻品，而是一个**跨引擎、分阶段的学习载体**：

- 同一个游戏设计，在三个引擎中各实现一次，每次专注体会引擎差异
- 每一站都完整走完"原型 → 垂直切片 → 测试 → 打磨 → 发布"的独立游戏开发循环
- 素材、数值、设计文档全部引擎无关，可跨引擎复用

## 三站路线总览

| 阶段 | 引擎 | 形态 | 核心学习目标 |
|------|------|------|--------------|
| 第一站 | Axmol（Cocos2d-x C++ 裸引擎） | 微信小游戏（2D，WASM 适配上架） | 引擎与渲染管线原理、完整开发流程、性能预算、上架合规 |
| 第二站 | Unity | 移动端 App（2D） | C# 组件架构、URP/Shader、移动端发布链路 |
| 第三站 | Unreal Engine | 3D 精神续作 | 材质/光照/后处理、蓝图→C++、现代渲染管线 |

详细路线图见 `docs/02-学习路线图.md`。

## 铁律（每次想贪多时回来看这三条）

1. **串行推进**：同一时间只碰一个引擎，上一站里程碑达成才准开下一站。
2. **范围纪律**：每个引擎版本先复刻 MVP（一张图、五种怪、点射+3技能、局外升级），再谈加料。
3. **发布即验收**：每站以"真实发布"为终点（小游戏上线 / 安卓包给朋友装 / UE 可玩 Demo），不做永远只差一点的半成品。
